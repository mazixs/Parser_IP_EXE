# Parser_IP_EXE

Утилита для мониторинга сетевых подключений заданных процессов Windows, сбора их IP-адресов, проверки пинга и сопоставления с доменными именами. Результаты сохраняются для последующего анализа и автоматизации маршрутизации.

---

## Как пользоваться (максимально просто)

### 1. Установка
- Убедитесь, что установлен Python 3.12 или новее.
- Скачайте и распакуйте архив с программой или клонируйте репозиторий.
- Откройте папку с программой.
- Установите зависимости командой:
  ```bash
  pip install psutil
  ```

### 2. Настройка конфигурации
- Откройте файл `config.toml` в любом текстовом редакторе.
- Пример содержимого и пояснения:
  ```toml
  [Processes]
  exe_list = ["chrome.exe", "python.exe"] # Список процессов для отслеживания (важно: регистр букв!)

  [Output]
  ip_file = "ip.txt"           # Файл для списка IP
  keenetic_file = "keenetic.bat" # Файл для команд маршрутизации
  ping_file = "ping.log"       # Файл для логов пинга
  domain_file = "domain.txt"   # Файл для доменных имен

  [Ping]
  enable_ping = 1               # 1 — включить пинг, 0 — выключить

  [Threading]
  max_ping_threads = 2          # Сколько потоков для пинга одновременно
  max_active_tasks = 4          # Сколько задач пинга одновременно
  ping_delay = 0.5              # Задержка между пингами (сек)
  ping_interval = 600           # Интервал повторного пинга (сек)

  [Domain]
  enable_domain_tracking = 1    # 1 — собирать домены, 0 — нет

  [Subnet]
  mask = "32"                  # Маска подсети: 16, 24 или 32
  ```
- **Важно:**
  - В `exe_list` указывайте только имена процессов, как они отображаются в диспетчере задач (например, "chrome.exe").
  - Если программа не видит нужный процесс — проверьте регистр букв и правильность написания.

### 3. Запуск программы
- Запустите команду:
  ```bash
  python parser.py
  ```
- Программа создаст папку `results/` (если её нет) и подпапку с датой и временем запуска.

### 4. Где искать результаты
- В папке `results/YYYY-MM-DD_HH-MM-SS/` появятся файлы:
  - `ip.txt` — уникальные IP-адреса отслеживаемых процессов
  - `keenetic.bat` — команды для маршрутизатора Keenetic
  - `ping.log` — лог результатов пинга
  - `domain.txt` — сопоставление IP и доменных имен

### 5. Для чего нужны IP и домены
- IP-адреса позволяют понять, с какими серверами работают ваши процессы.
- Доменные имена помогают узнать, к каким сайтам или сервисам идут подключения.
- Пинг показывает, доступны ли эти адреса и как быстро до них доходит сигнал.

### 6. Часто задаваемые вопросы (FAQ)
- **Q:** Программа не видит мой процесс.
  **A:** Проверьте, как он называется в диспетчере задач. Убедитесь, что регистр букв совпадает.
- **Q:** В ip.txt пусто.
  **A:** Возможно, процессы не установили сетевых соединений на момент запуска. Подождите или перезапустите программу.
- **Q:** Не создаются файлы результатов.
  **A:** Проверьте права на запись в папку, корректность настроек в config.toml.
- **Q:** Как добавить новый процесс?
  **A:** Просто добавьте его имя в список `exe_list` через запятую.

### 7. Типичные ошибки
- Неправильный регистр в имени процесса.
- Программа запущена не из той папки.
- Не установлен Python или psutil.
- Ошибки в формате config.toml (например, лишние запятые или кавычки).

## Структура проекта
- `parser.py` — основной скрипт мониторинга и логики.
- `config.toml` — конфигурационный файл (настраиваются процессы, файлы вывода, параметры пинга и доменов).
- `modules/` — все вспомогательные модули: `config.py`, `network.py`, `utils.py`, `logging_utils.py` и др.
- `results/` — автоматически создаваемая папка для выходных файлов. Для каждого запуска создаётся отдельная подпапка с датой и временем (`results/YYYY-MM-DD_HH-MM-SS/`):
  - `ip.txt` — список уникальных IP-адресов отслеживаемых процессов
  - `keenetic.bat` — команды маршрутизации для Keenetic
  - `ping.log` — лог результатов пинга
  - `domain.txt` — сопоставление IP и доменных имен
- `tests/` — модульные тесты для ключевых функций

## Технический стек
- Python 3.12+
- [psutil](https://pypi.org/project/psutil/) >=5.9 — работа с процессами и сетевыми соединениями
- [tomllib](https://docs.python.org/3/library/tomllib.html) (стандарт с Python 3.11) — парсинг TOML
